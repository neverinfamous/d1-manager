# D1 Manager v2.0.0

## Highlights

- **Drizzle ORM Studio**: Introspect schemas, generate TypeScript definitions, and push schema migrations directly to D1.
- **Scheduled R2 Backups**: Automate daily, weekly, or monthly database backups to Cloudflare R2 via Durable Objects.
- **Metrics Dashboard**: Monitor read/write query volume, rows read, and P90 latency with lightweight SVG charts.
- **Unified Backup Hub**: Manage quick undos, R2 snapshots, and automated schedules from a centralized interface.

## Added

- **drizzle**: Introspect D1 databases to generate Drizzle TypeScript schemas, validate migrations, and push schema changes.
- **backups**: Schedule automated daily, weekly, or monthly R2 backups with configurable execution hours.
- **backups**: Unify quick undo snapshots, R2 cloud backups, and schedule management into a single tabbed dialog.
- **backups**: Protect databases with automatic pre-operation backups before renaming, deleting, or enabling STRICT mode.
- **metrics**: Visualize query volume, rows read, P90 latency, and per-database storage with accessible SVG charts.
- **ui**: Toggle between list and grid views for databases and tables, and expand diagrams to fullscreen.

## Changed

- **performance**: Accelerate ER diagram loading by 60-70% using single-query schema fetching instead of N+1 requests.
- **performance**: Add client-side caching across tables, schemas, foreign keys, and metrics to eliminate redundant API calls.
- **logging**: Standardize application logging with module-prefixed error codes across 330+ locations.

docker pull writenotenow/d1-manager:v2.0.0
