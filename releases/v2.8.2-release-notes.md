# D1 Manager v2.8.2

## Highlights

- **Strict Origin & CSRF Protection**: Credentialed CORS and state-changing API requests now require trusted origins, blocking unauthorized cross-site mutations.
- **Hardened Local Dev Detection**: Authentication bypasses for mock mode now strictly verify the canonical request URL and active credentials instead of client headers.
- **Refreshed Dependencies & Container Security**: Core packages, Alpine libraries, and bundled npm dependencies are updated to resolve the latest advisories.

## Changed

- **deps**: Updated `@cloudflare/workers-types`, `@types/node`, `dompurify`, `jose`, `lucide-react`, `sql-formatter`, `typescript-eslint`, `vite`, `wrangler`, and `zod`.
- **ci**: Updated GitHub Actions workflows and Docker build dependency overrides.

## Security

- **cors**: Restricted credentialed CORS responses to same-origin or `ALLOWED_ORIGINS` and rejected untrusted cross-origin `POST`, `PUT`, `PATCH`, and `DELETE` requests with `403 Forbidden`.
- **auth**: Prevented potential authentication bypass by evaluating `isLocalDevEnvironment` from the request hostname and missing production secrets rather than the `Origin` header.
- **worker**: Disabled `workers_dev` and `preview_urls` routes by default in `wrangler.toml` so traffic routes exclusively through Cloudflare Access.
- **docker**: Patched bundled npm packages (`undici`, `tar`, `minimatch`, `picomatch`, `ip-address`) and upgraded Alpine system packages in the runtime image.

## Install

```bash
docker pull writenotenow/d1-manager:v2.8.2
```
