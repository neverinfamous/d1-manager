# D1 Manager v1.1.0

## Highlights

- **Time Travel & Checkpoints**: Capture point-in-time bookmarks and generate copy-ready Wrangler restore commands before destructive changes.
- **Read Replication Management**: Monitor replication status and toggle read replication directly from the dashboard.
- **Job History & Audit Timeline**: Track bulk operations with granular progress milestones, error filtering, and detailed event logs.
- **Cascade Simulator & FK Visualizer**: Simulate foreign key cascade impacts and edit relationships visually with ReactFlow graphs.

## Added

- **replication**: Monitor read replication status and toggle replication modes with regional query serving info.
- **time-travel**: Capture point-in-time database bookmarks automatically before destructive operations and generate CLI restore commands.
- **jobs**: Track bulk operation progress and error milestones with audit event timelines, filtering, and sorting.
- **dependencies**: Simulate foreign key cascade deletions interactively and export impact reports in PDF, CSV, and JSON.
- **undo**: Restore dropped tables and modified schemas with an automated 10-operation snapshot history per database.
- **foreign-keys**: Visualize, create, modify, and delete foreign key constraints using an interactive node graph with orphan detection.
- **fts5**: Create and configure FTS5 full-text search virtual tables with custom tokenizers and BM25 search interface.
- **schema**: Analyze database indexes with one-click recommendations and detect circular table dependencies.

## Changed

- **filters**: Expand row filtering to support OR logic, BETWEEN ranges, IN operators, and saved filter presets.
- **navigation**: Navigate foreign key relationships directly from table cells with breadcrumb history.

## Fixed

- **types**: Enforce TypeScript strict mode across frontend and worker codebases, resolving over 100 type safety issues.

## Install

```bash
docker pull writenotenow/d1-manager:v1.1.0
```
