# D1 Manager v2.8.1

## Highlights

- **Clean Docker Image**: The container now scans at zero known vulnerabilities across all severities. You can deploy it with confidence.
- **Fresh Dependencies**: React 19.3, Vite 8.3, Wrangler 4.156 and more. You stay current without any behavior changes.

## Changed

- **deps**: Updated all dependencies and refreshed security overrides for `tar`, `minimatch`, `picomatch`, `brace-expansion`, `flatted`, and `ip-address`.
- **docker**: Patched npm's bundled packages, upgraded Alpine system libraries, and removed pnpm's cached runtime from the final image.
- **ci**: Refreshed GitHub Actions to the latest pinned releases and pinned runners to `ubuntu-24.04`.

## Fixed

- **lint**: Replaced no-op statements with explicit state clearing in the database view, diff editor, FTS5 manager, and webhooks route. Error states now reset cleanly.

## Security

- **docker**: Eliminated all known CVEs in the published image, verified with Docker Scout.

## Install

```bash
docker pull writenotenow/d1-manager:v2.8.1
```
