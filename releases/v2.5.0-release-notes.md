# D1 Manager v2.5.0

## Highlights

- **Node.js 24 LTS Upgrade**: Modernizes runtime and build pipelines to the latest Node.js 24 LTS standard.
- **Query Builder Enhancements**: Fixes result feedback on zero-row queries and adds CSV export support.
- **Security & Quality Hardening**: Patches 4 vulnerabilities and achieves zero ESLint disable comments.

## Added

- **query-builder**: Add CSV export capability for Query Builder result sets matching SQL Editor parity.

## Changed

- **runtime**: Upgrade runtime and Docker base images to Node.js 24 LTS (`node:24-alpine`) with updated engines constraint.
- **code-quality**: Remediate all `eslint-disable` comments across 15 React components using hook memoization.
- **ci**: Restructure Docker publishing workflow to require passed security vulnerability scans before pushing.
- **deps**: Update Wrangler to 4.64.0, React to 19.2.4, and related build tooling dependencies.

## Fixed

- **query-builder**: Fix results panel visibility when queries return zero rows, ensuring execution feedback and metadata display.

## Security

- **tar**: Patch CVE-2026-24842, CVE-2026-23745, and CVE-2026-23950 by overriding tar to 7.5.7.
- **brace-expansion**: Add override for `@isaacs/brace-expansion` ^5.0.1 to mitigate GHSA-7h2j-956f-4vf2 ReDoS vulnerability.
- **error-handling**: Implement `classifySqlError` allowlist to prevent stack trace exposure in API responses.

## Install

```bash
docker pull writenotenow/d1-manager:v2.5.0
```
