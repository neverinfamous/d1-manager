# D1 Manager v2.6.3

## Highlights

- **Dependency & Tooling Modernization**: Upgraded Cloudflare Workers types, Wrangler, and ESLint tooling for enhanced stability.
- **Supply Chain Security**: Patched transitive `tar` dependencies across npm and Docker layers.
- **CI/CD Reliability**: Upgraded Docker GitHub Actions to modern major versions for faster, secure releases.

## Changed

- **deps**: Updated `@cloudflare/workers-types` (`4.20260307.1` → `4.20260310.1`), `@types/node` (`25.3.5` → `25.4.0`), `jose` (`6.2.0` → `6.2.1`), `typescript-eslint` (`8.56.1` → `8.57.0`), and `wrangler` (`4.71.0` → `4.72.0`).
- **actions**: Upgraded `docker/setup-buildx-action` (v3 → v4), `docker/login-action` (v3 → v4), `docker/metadata-action` (v5 → v6), and `docker/build-push-action` (v6 → v7).

## Security

- **deps**: Updated `tar` dependency override (`7.5.10` → `7.5.11`) across npm and Docker container layers to remediate security advisories.

docker pull writenotenow/d1-manager:v2.6.3
