# D1 Manager v2.6.8

## Highlights

- **ESLint v10 Compliance**: Stabilized React hooks state synchronization for ESLint v10.
- **TypeScript Safety**: Resolved template literal safety bugs and IDE diagnostic divergences.
- **Core Updates**: Upgraded 15+ core dependencies including TypeScript 6.0.3, React 19.2.5, Vite 8.0.9, and Tailwind 4.2.4.

## Security

- **dompurify**: Fixed DOMPurify security vulnerability (GHSA-39q2-94rc-95cp).

## Fixed

- **hooks**: Stabilized ESLint v10 compliance via strict `Promise.resolve().then(...)` batching for React hooks (`react-hooks/set-state-in-effect`, `react-hooks/immutability`).
- **types**: Resolved deep TypeScript template literal type safety and `no-base-to-string` object leaking errors across Export, QueryBuilder, and TableView components.
- **ide**: Mitigated TypeScript 6.0/VS Code `baseUrl` IDE diagnostics divergence.
