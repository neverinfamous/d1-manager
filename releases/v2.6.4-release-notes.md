# D1 Manager v2.6.4

## Highlights

- **Critical Security Remediation**: Pinned `undici` to `7.24.4` to fix WebSocket overflow and HTTP Smuggling vulnerabilities.
- **Core Toolchain Updates**: Upgraded `esbuild`, `drizzle-kit`, and `@cloudflare/workers-types` for improved compilation and ORM capabilities.
- **Frontend Tooling Alignment**: Updated Vite React plugin and TypeScript ESLint rules for developer workflow consistency.

## Changed

- **deps**: Bumped `@types/node` from 25.4.0 to 25.5.0.
- **deps**: Bumped `esbuild` from 0.27.3 to 0.27.4.
- **deps**: Bumped `@cloudflare/workers-types` and `wrangler` to latest patch releases.
- **deps**: Bumped `drizzle-kit` from 0.31.9 to 0.31.10.
- **deps**: Bumped `jspdf` from 4.2.0 to 4.2.1.
- **deps**: Bumped `typescript-eslint` from 8.57.0 to 8.57.1.
- **deps**: Bumped `@vitejs/plugin-react` from 5.1.4 to 5.2.0.
- **actions**: Updated GitHub Actions CI dependencies.
