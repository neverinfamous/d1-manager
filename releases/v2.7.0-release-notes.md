# D1 Manager v2.7.0

## Highlights

- **Table View Overhaul**: Rebuilt the table architecture with Tanstack React Table v9 for improved modularity and performance.
- **Inline Cell Editing**: Edit cell values directly within the table grid, reducing friction for rapid data entry.
- **Predicate Column Filters**: Quickly filter data with advanced predicate-based column filters for more granular views.

## Added

- **table-view**: Implemented Tanstack React Table v9 integration with inline cell editing to accelerate data workflows.
- **table-view**: Added predicate column filters for precise data filtering and manipulation.

## Changed

- **table-view**: Extracted the monolithic Table View component into a highly modular, maintainable directory structure.
- **ci**: Updated pnpm/action-setup to v6, resolving Node 20 deprecation warnings and ensuring stable CI builds.

## Install

```bash
docker pull writenotenow/d1-manager:v2.7.0
```
