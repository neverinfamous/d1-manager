# D1 Manager v2.6.9

## Highlights

- **Query Console Fix**: Resolved production blank page crash caused by Prism initialization ordering.
- **Dependency Updates**: Updated 9 key dependencies including ESLint, Vite, Wrangler, and Cloudflare Workers Types.

## Fixed

- **query-console**: Fixed Query Console blank page with `Uncaught ReferenceError: Prism is not defined` in production builds since v2.6.5 ([#124](https://github.com/neverinfamous/d1-manager/issues/124))
  - Split `prismjs` into its own `vendor-prism` chunk to prevent Rolldown from reordering module initialization when co-bundled with `sql-formatter` in the `vendor-sql` chunk

## Changed

- **deps**: Bumped `@cloudflare/workers-types` from 4.20260422.1 to 4.20260505.1
- **deps**: Bumped `eslint` from 10.2.1 to 10.3.0
