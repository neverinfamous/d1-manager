# D1 Manager v2.1.0

## Highlights

- **AI Semantic Search**: Index database schemas and records into Cloudflare AI Search for natural language querying.
- **Fleet Health Dashboard**: Track overall system health with automated scoring based on backup coverage and job status.
- **13-Event Webhook Engine**: Broadcast granular database lifecycle, DDL, and snapshot events to external webhooks.
- **TailwindCSS v4 Migration**: Modernize styling infrastructure with CSS-first configuration and faster build times.

## Added

- **ai-search**: Export database schemas and table records to R2 for semantic search and AI-assisted querying via AutoRAG.
- **health**: Monitor database fleet health with 0-100 scoring, backup coverage alerts, and failed job tracking.
- **webhooks**: Dispatch webhooks across 13 lifecycle events covering database mutations, table DDL, and backup operations.
- **backups**: Display timeout warnings when configuring scheduled backups for databases containing FTS5 tables.

## Changed

- **ui**: Upgrade styling architecture to TailwindCSS v4 with `@tailwindcss/vite` and CSS-first `@theme` definitions.
- **ci**: Enforce strict CI/CD gating requiring lint and CodeQL analysis before building Docker release images.
- **deps**: Organize Dependabot updates into categorized groups for npm, GitHub Actions, and Docker.

## Fixed

- **react**: Resolve React error #527 by aligning `react-dom` dependency versions with React 19.2.3.
- **backups**: Increase backup export timeout from 2 to 6 minutes to prevent failures on large databases.
- **config**: Add missing scheduled backup cron trigger configurations to `wrangler.toml`.
- **performance**: Replace 2MB placeholder favicon with an inline SVG to reduce initial bundle payload.
- **types**: Fix return type definitions in ordinal formatting utility.

## Security

- **deps**: Update `jspdf` to 4.0.0 and enforce `glob` 11.1.0 to address CVE-2025-64756.

## Install

```bash
docker pull writenotenow/d1-manager:v2.1.0
```
