# D1 Manager v2.3.0

## Highlights

- **Query Insights Tab**: Identify and optimize slow database queries with Cloudflare GraphQL Analytics integration.
- **Performance Summary Cards**: Gain instant visibility into critical, moderate, and fast query execution buckets.

## Added

- **metrics**: Introduce Query Insights tab powered by Cloudflare's `d1QueriesAdaptiveGroups` API for slow query analysis.
- **metrics**: Add performance summary cards categorizing queries into Critical (>100ms), Moderate (50-100ms), and Fast (<50ms).
- **metrics**: Add sortable query table supporting sorting by total time, average time, execution count, and rows read.
- **metrics**: Provide expandable query details displaying complete SQL statements and detailed metrics.
- **metrics**: Include color-coded performance badges and a tabbed interface separating overview charts from query insights.

## Changed

- **deps**: Update `@cloudflare/workers-types` from 4.20260103.0 to 4.20260107.1 and add `@radix-ui/react-tabs`.

## Install

```bash
docker pull writenotenow/d1-manager:v2.3.0
```
