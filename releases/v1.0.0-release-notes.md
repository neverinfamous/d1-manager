# D1 Manager v1.0.0

## Highlights

- **Visual Database & Table Management**: Manage Cloudflare D1 databases and schemas visually with full CRUD operations and bulk actions.
- **Foreign Key Dependency Analysis**: Prevent accidental data loss with inbound and outbound dependency previews before table deletions.
- **Zero Trust Security**: Secure database administration with Cloudflare Access JWT validation and unprivileged Docker containers.

## Added

- **databases**: Manage D1 databases with full CRUD operations, migration-based renaming, and bulk download/delete/optimize actions.
- **tables**: Design schemas visually with type definitions, constraints, default values, and live SQL preview.
- **tables**: Browse and paginate table data, with bulk table cloning, export, and dependency-checked deletion.
- **columns**: Add, rename, modify, and drop columns with automatic data migration and index preservation.
- **filters**: Filter table rows using type-aware operators and shareable URL query parameters.
- **dependencies**: Inspect inbound and outbound foreign key relationships with cascade behavior warnings before deleting tables.
- **query-console**: Execute custom SQL queries with syntax highlighting, execution history, and CSV export.
- **auth**: Authenticate users securely via Cloudflare Access Zero Trust with JWT validation.
- **docker**: Deploy multi-architecture Docker containers with non-root security and health check endpoints.
- **ui**: Switch between dark, light, and system themes with a responsive layout built on shadcn/ui.

## Install

```bash
docker pull writenotenow/d1-manager:v1.0.0
```
