# D1 Manager v2.4.0

## Highlights

- **Schema Migration Generation**: Compare databases and generate executable SQL migration scripts with risk classification.
- **Direct Migration Execution**: Apply generated migration scripts directly to target databases with SQLite constraint handling.

## Added

- **schema**: Full database schema comparison across tables, columns, indexes, foreign keys, and triggers.
- **migrations**: Generate executable SQL migration scripts with safety risk classifications (safe, warning, danger).
- **migrations**: Direct migration execution against target databases with confirmation and idempotent column addition.
- **export**: Export migration scripts via clipboard copy or `.sql` file download.
- **api**: Add `GET /api/tables/:dbId/schema-full` endpoint for comprehensive schema introspection.

## Changed

- **deps**: Update Wrangler to 4.59.1, @cloudflare/workers-types to 4.20260113.0, diff to 8.0.3, and related dependencies.

## Fixed

- **dev-server**: Fix `Cannot read properties of undefined (reading 'fetch')` error during local development with `wrangler.dev.toml`.

## Security

- **security**: Document non-exploitability of CVE-2026-22184 (untgz buffer overflow) in D1 Manager.

## Install

```bash
docker pull writenotenow/d1-manager:v2.4.0
```
