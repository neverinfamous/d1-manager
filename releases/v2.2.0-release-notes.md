# D1 Manager v2.2.0

## Highlights

- **Portable Export Formats**: Export databases with full schema metadata as SQL, structured JSON, or zipped CSV archives.
- **Universal Data Import**: Create new databases or restore existing ones from SQL, JSON, or CSV/ZIP source files.
- **Batch Export Format Selection**: Select export file formats and track progress with built-in API rate limiting during bulk downloads.

## Added

- **export**: Export database tables and schemas to SQL dumps, structured JSON, or CSV/ZIP archives with schema definitions.
- **import**: Import databases from SQL, JSON, or CSV/ZIP sources with schema inference and pre-import table previews.
- **bulk-export**: Select preferred export formats when performing bulk database downloads with real-time progress bars.

## Changed

- **rate-limiting**: Implement 300ms inter-table delays with exponential backoff retries to prevent API throttling during exports.
- **dev-env**: Streamline local development by auto-loading `.env.development` in Vite without manual file toggling.
- **docker**: Upgrade base Docker container runtime from Node.js 20-alpine to Node.js 22-alpine.
- **deps**: Pin `wrangler` to 4.54.0 to circumvent upstream peer dependency issues in 4.56.0.

## Fixed

- **import**: Automatically refresh the database list upon import completion without requiring a manual page reload.
- **ci**: Ensure Docker publish workflows fail immediately on CodeQL security errors.

## Security

- **ai-search**: Prevent markdown escaping bypasses during AI Search exports by escaping backslashes before pipe characters.

## Install

```bash
docker pull writenotenow/d1-manager:v2.2.0
```
