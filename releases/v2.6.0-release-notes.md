# D1 Manager v2.6.0

## Highlights

- **ESLint 10 Upgrade**: Adopts ESLint 10 across the entire codebase with complete rule compliance.
- **AI Search Modernization**: Migrates to Cloudflare's latest `aiSearch()` API with backward compatibility.
- **CI/CD Hardening**: Restricts Docker publish workflows to tag pushes and enforces exact dependency pinning.

## Changed

- **ai**: Migrate deprecated `autorag()` integration to Cloudflare `aiSearch()` with a backward-compatible adapter.
- **linting**: Upgrade ESLint from 9.39.2 to 10.0.3 and resolve 14 lint violations across the project.
- **git**: Transition primary branch references from `master` to `main` across all GitHub Actions workflows.
- **deps**: Update Wrangler to 4.71.0, Tailwind CSS to 4.2.1, jose to 6.2.0, and related libraries.

## Security

- **minimatch**: Patch GHSA-3ppc-4f35-3m26, GHSA-7r86-cg39-jmmj, CVE-2026-27903, and CVE-2026-27904 by updating minimatch to 10.2.4.
- **tar**: Patch CVE-2026-26960 path traversal vulnerability by updating tar override to 7.5.8.
- **dependencies**: Enforce exact version pinning on glob, tar, and minimatch overrides to eliminate lockfile drift.

## Removed

- **workflows**: Remove Dependabot auto-merge workflow to ensure manual review of dependency updates.
- **config**: Remove redundant `VERSION` file in favor of direct `package.json` version extraction.

## Install

```bash
docker pull writenotenow/d1-manager:v2.6.0
```
