# D1 Manager v2.6.5

## Highlights

- **Major Toolchain Upgrades**: Rebased onto Vite 8, TypeScript 6, esbuild 0.28, and Lucide React 1.7.
- **Transitive Security Hardening**: Added explicit npm and Docker overrides for `tar`, `minimatch`, `picomatch`, and `flatted` against known CVEs.

## Changed

- **build**: Upgraded `vite` to `8.0.4` and `@vitejs/plugin-react` to `6.0.1`, refactoring `vite.config.ts` with functional `manualChunks` for Rollup 4 compatibility.
- **types**: Upgraded `typescript` to `6.0.2` and refined `useState`/`useRef` strict inferences across context and AI Search modules.
- **deps**: Upgraded `esbuild` to `0.28.0` and `lucide-react` to `1.7.0`.

## Security

- **docker**: Patched Docker build transitive dependency `tar` to `7.5.13` to resolve vulnerabilities.
- **deps**: Enforced npm overrides for `flatted` (v3.4.2), `picomatch` (v4.0.4), `tar` (v7.5.13), and `minimatch` (v10.2.5) against upstream CVEs.

## Install

```bash
docker pull writenotenow/d1-manager:v2.6.5
```
